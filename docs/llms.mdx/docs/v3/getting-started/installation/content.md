# Installation [#installation]

Please ensure your environment meets the following requirements:

* [git](https://git-scm.com/downloads)
* [Node.js](https://nodejs.org/en/download&#x29; &#x2A;*>= 22 (LTS)**
* [MongoDB](https://www.mongodb.com/try/download/community&#x29; **> 4.2** (MongoDB 6.0 or 7.0+ recommended)

***

Clone the Burni repository with Git:
