# Installation
請確認您的環境有以下內容：

- [git](https://git-scm.com/downloads)
- [Node.JS](https://nodejs.org/zh-tw/download)
- [MongoDB](https://www.mongodb.com/try/download/community) > 4.2
## 使用 git
- 從 git 複製專案

<CodeBlockTabs defaultValue="bash">
    <CodeBlockTabsList>
        <CodeBlockTabsTrigger value="bash">bash</CodeBlockTabsTrigger>
    </CodeBlockTabsList>

    <CodeBlockTab value="bash">

    </CodeBlockTab>
</CodeBlockTabs>

-  安裝套件

</CodeBlockTabs>
