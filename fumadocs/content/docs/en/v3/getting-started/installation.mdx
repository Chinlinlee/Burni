# Installation

Please ensure your environment meets the following requirements:

- [git](https://git-scm.com/downloads)
- [Node.js](https://nodejs.org/en/download) **>= 22 (LTS)**
- [MongoDB](https://www.mongodb.com/try/download/community) **> 4.2** (MongoDB 6.0 or 7.0+ recommended)

---

## 1. Clone the Repository

Clone the Burni repository with Git:

<CodeBlockTabs defaultValue="bash">
    <CodeBlockTabsList>
        <CodeBlockTabsTrigger value="bash">bash</CodeBlockTabsTrigger>
    </CodeBlockTabsList>

    <CodeBlockTab value="bash">
    ```bash
    git clone https://github.com/Chinlinlee/Burni.git
    cd Burni
    ```
    </CodeBlockTab>
</CodeBlockTabs>

---

## 2. Install Dependencies

Install required dependencies by running `npm install`:

    <CodeBlockTabsList>

    </CodeBlockTabsList>
