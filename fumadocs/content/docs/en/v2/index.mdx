# Burni v2 (LTS) Documentation Guide

Welcome to the **Burni v2 (LTS)** documentation. Burni is a high-performance FHIR R4 (v4.0.1) server built with Node.js, Express, and MongoDB / Mongoose.

The v2 series represents our battle-tested, production-ready Long Term Support release, providing mature FHIR resource storage, validation, and search capabilities.
